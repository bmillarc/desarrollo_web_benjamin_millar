 # Tarea 1 - Desarrollo Web
   
   ## Descripción
   Esta tarea incluye la implementación de una página HTML con CSS y JS.
   Esta consiste en una pagina para agregar y visualizar actividades que se realizaran en algun momento y lugar.
   
   ## Decisiones tomadas
   - Para ver las fotos en mayor tamaño cree una pagina para cada una de estas usando la imagen como link.
   - En los listados se usaron tablas
   - La informacion de todo es inventada.
   - No logre implementar los validadores de la fecha, los contactos y los documentos por completo, solo parte de estos.
   - Mucho del codigo esta basado en los auxiliares, especialmente el formulario.
